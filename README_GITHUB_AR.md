# أطلس القراءات العشر — حزمة GitHub Pages 0.5.1

هذه ملفات الموقع الجاهزة للرفع. يجب أن يكون `index.html` ومجلد `assets` في جذر المستودع.

## الرفع بواسطة GitHub Desktop

هذه النسخة تحتوي أكثر من 100 ملف؛ الرفع بواسطة GitHub Desktop هو الأسهل للحفاظ على مجلدات المكتبة. الموقع لا يحتاج البرنامج بعد النشر.

1. نزّل GitHub Desktop من https://desktop.github.com وسجّل الدخول بحسابك.
2. أنشئ مستودعاً محلياً باسم مثل qiraat-atlas، أو استنسخ مستودع الموقع الموجود.
3. افتح مجلد المستودع على جهازك، وانسخ إليه محتويات هذه الحزمة: index.html وassets والملفات المرفقة، دون وضعها في مجلد خارجي إضافي.
4. احفظ التغييرات بواسطة Commit ثم Publish repository للمستودع الجديد، أو Push origin للمستودع الموجود. إذا أردت موقعاً عاماً فاجعل المستودع عاماً.
5. من GitHub > Settings > Pages اختر Deploy from a branch ثم main و/(root).

## الرفع من المتصفح

1. أنشئ مستودعاً عاماً في GitHub، أو افتح مستودع الموقع الذي تريد تحديثه.
2. يتيح GitHub رفع 100 ملف في الدفعة الواحدة؛ ارفع على دفعات مع المحافظة على المسارات، أو استخدم GitHub Desktop أعلاه. مرجع الحد: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository .
3. فك ضغط الحزمة على جهازك. لا تستخدم فتح index.html كملف محلي لاختبار مكتبة المرجع؛ شغّلها عبر رابط الموقع أو خادم محلي لأن المكتبة تحمّل نصوص السور عند الطلب. ارفع الملفات والمجلدات الموجودة داخلها، لا الملف المضغوط نفسه، ولا المجلد الخارجي الذي يحتويها. حافظ على مجلد `assets` ومحتوياته.
4. من Settings > Pages اختر Deploy from a branch، ثم `main` و`/(root)`، واحفظ.
5. انتظر نجاح عملية Pages ثم افتح الرابط المعروض. تعمل الروابط النسبية تحت اسم أي مستودع.

لا تحتاج هذه الحزمة إلى npm أو مفاتيح API أو خادم خلفي. المحفوظات في المتصفح، والبحث في الملفات المحلية، والتسجيلات روابط خارجية من المصدر. قد يستغرق التحميل الأول وقتاً بحسب الاتصال.

## إصلاح البحث على الهاتف

أصبح صندوق البحث في بداية الصفحة قبل المقدمة، بعنوان ظاهر «ابحث في القرآن والقراءات». القائمة على الهاتف خلف زر ☰، وأدوات حجم الخط مطوية حتى فتحها. التخطيط الشبكي يعطي حقل الكتابة عرضاً مرناً؛ ويُوضع زر البحث في صف مستقل عند صغر العرض أو تكبير الخط.

لتحديث الموقع المرفوع، استبدل index.html وملفات assets بنظائرها من هذه الحزمة، بما فيها navigation.js وfont-size.js وreadability.css وstyle.css، وحافظ على المسارات. لا ترفع ZIP وحده. يشير تذييل الصفحة إلى الإصدار 0.5.1؛ إن بقي 0.4.1 فالنشر لم يتحدث أو الصفحة مخزنة. بعد نجاح نشر GitHub أعد تحميل الصفحة على الهاتف.

## ترتيب نتائج البحث

في الإصدار 0.4.3 تقدّم المطابقة الكاملة للكلمة على المطابقة الجزئية: عند البحث عن «ولدا» يظهر موضع مريم 88 قبل «ولدار» في الأنعام 32. تبقى المطابقات الجزئية متاحة مع بيان نوعها. لا يتغير ترتيب المراجع الصريحة أو البيانات العلمية.

## وضوح الخط

اضغط «حجم الخط» أعلى المحتوى لفتح أدواته المطوية: تكبير حتى 200%، وتصغير، واستعادة الافتراضي. يتذكر المتصفح اختيار الزائر. الأحجام الافتراضية أكبر، ولون الشروح أوضح، ويتكيف التخطيط عند التكبير. بعد تحديث نسخة قديمة على GitHub أعد تحميل الصفحة إذا بقيت ملفاتها مخزنة في المتصفح.

## مكتبة التوجيه وأدوات البحث

تضم المكتبة نص «الدر المصون» كما أتاحته قاعدة المصدر: 4,820 مدخلاً من 114 سورة و11,202 مقطعاً. اختر السورة ورقم الآية، أو ابحث بعبارة داخل السورة المحددة. افتح نص المرجع لقراءة المقاطع ونسخ إحالات الأجزاء والصفحات وطباعتها. بعض المقاطع غير مرقمة في المصدر. هذه نصوص مرجعية، لا توجيه محرر لكل وجه، وقد تتناول آيات مجاورة وقراءات خارج العشر.

التصدير متاح بصيغتي JSON وCSV. جدول المقارنات يحتفظ بوصف الأداء وقيد الطريق ونسبة كل راوٍ ومصدره؛ إذا تعددت أوجه الراوي ظهرت في صفوف منفصلة. تستطيع طباعة تفاصيل المقارنة، أو تنزيل محفوظاتك واستيرادها على جهاز آخر دون محو السابقة.

## توجيه القراءات

أُضيف قسم توجيه القراءات إلى تفاصيل المواضع المدعومة، مع وجه كل قراءة في اللغة والمعنى ومراجعها وزر نسخ إحالتها. تضم هذه الدفعة 11 موضوعاً موثقاً مرتبطاً بـ20 سجلاً. من حالة التوثيق اختر «مواضع ذات توجيه موثّق». توجيه بقية الكلمات لم يُدرج بعد، ولا يُولّد تفسير تلقائياً.

## التحقق بعد الرفع

- ابحث عن «يغل» أو «آل عمران 161»، وافتح تفاصيل المقارنة المراجعة.
- جرّب «جميع الكلمات»، ثم افتح كلمة من الآية لعرض ارتباطاتها.
- افتح سجل أداء متعدد الأوجه وقارن روايتين، ثم جرّب التصدير والمحفوظات.
- افتح «مكتبة التوجيه»، واختر آل عمران 161 وراجع الصفحات 465–468.
- نزّل نسخة محفوظات وجرّب استيرادها، وصدّر مقارنة CSV وافتحها بترميز UTF-8.
- افتح «مدخل إلى العلم > منهج الأطلس» لتغطية كل سورة وسجل التصحيحات.

## حدود النسخة والحقوق

اقرأ `DATA_REVIEW_AR.md`. البحث يشمل جميع كلمات النص المرجعي؛ لا تدعي القاعدة استيعاب جميع أوجه القراءات وطرقها أو مراجعة كل وصف مستورد.

الموسوعة القرآنية https://quranpedia.net — إصدار بيانات القراءات 2026-10-10، وإصدار نص الدر المصون 2026-08-10. أبق النسبة والرابط والإصدار وشروط المصدر عند إعادة توزيع القاعدة. التراخيص وإذن تيسير القراءات وشروط تنزيل وإحالات المصادر محفوظة في `assets` ومنهج الموقع. شواهد تيسير القراءات للاستخدام غير الربحي وفق إذن المصدر؛ لا يُفترض إذن تجاري شامل.

ملفات هذه الحزمة للنشر؛ مصدر التطوير ومترجم البيانات متاحان في حزمة المصدر المنفصلة. لا تشغّل build_data.py وحده عند تحديث البيانات الموسعة؛ الأمر الصحيح في المصدر هو python3 build_complete.py.

## تحديث المراجعة العلمية 0.5.0

ارفع ملفات حزمة التحديث بعد فك الضغط مع المحافظة على مجلد assets، واستبدل الملفات القديمة. أضف review.html إلى جذر الموقع؛ افتحه من رابط التقرير في قسم المنهج. ارفع ملفات الحزمة المفكوكة نفسها، ولا ترفع ZIP وحده. اختبر البحث 2:127، ثم افتح الصراط في الفاتحة للتحقق من ظهور قيود ابن شنبوذ ووجهي خلاد.

التقرير يفصل ما ثبت وما بقي؛ لا يدعي اكتمال جميع طرق العشر أو أصولها.

## تحديث 0.5.1 والرجوع

فك ضغط حزمة التحديث وارفع كل ملفاتها مع استبدال الموجود والمحافظة على المسارات. أضيف review-next.html وassets/document-back.js. لا ترفع ZIP وحده. افتح مقارنة يغل ثم مكتبة التوجيه؛ سهم الرجوع في أسفل الصفحة يعيدك إلى المقارنة وموضع قراءتها. وفي النص الكامل يرجع السهم إلى النص السابق أو القائمة. على الهاتف يظهر الزر بعرض المساحة المتاحة.

يوثق التقرير مراجعة الياءات وآل عمران والمسائل المؤجلة، ولا يعلن اكتمال علم القراءات أو تحقيق الصوت.
